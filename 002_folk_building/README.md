# 002 — برج حصن + مجلس (مبنى شعبي ثانٍ)

مبنى شعبي ثانٍ يُضاف **على يمين** البيت 001 داخل نفس المشهد، فيتكوّن حي صغير.
يُبنى بالكود ويعيد استخدام دوال وخامات `001_folk_house/fh_build.py` حتى يبقى متناسقاً.

## المكوّنات

**البرج (حصن/مراقبة)** — 4.6 × 6.0 م بارتفاع 8.6 م:
- جدران طينية 0.55 م مع فتحات بـ Boolean نظيفة (باب + مشكاتان + فتحة جانبية).
- سقف + سور محاط بشرافات مثلثة، و3 صفوف عوارض أثل.
- باب خشبي بعوارض حديد ومسامير وحلقة طرق، وإفريز مثلثات جصية.

**المجلس (ديوانية مفتوحة)** — 5.8 × 6.0 م:
- أرضية طينية مرتفعة 0.28 م، جدار خلفي وجانبي، رواق أمامي من 5 أعمدة خشبية.
- سقف من عوارض جريد وحصير سعف.

**الملحقات:** فناء مدكوك، أزيار، دكّة بوسادة، فانوس على عمود، نخلة وشجرتا سدر.
