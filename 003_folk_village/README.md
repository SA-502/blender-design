# 003 — قرية شعبية كاملة (للعبة)

قرية صحراوية صغيرة مبنية بالكود فوق مشهد 001/002: **مسجد + سوق + بيوت + تفاصيل**، بنفس الطابع النجدي (طين، جريد، أخشاب أثل، جص أبيض).

## المحتويات

**المسجد** (شرق السوق):
- قاعة صلاة 7×9.5م بسقف مسطح وسور، وقبة بيضاء (قطر 6م) على طنبور.
- مئذنة مربعة 10.8م: شرفة/دكة مراقبة + قبة صغيرة + هلال نحاسي.
- فناء محاط بسور منخفض، مدخل بعقد نصف دائري، محراب نافذة مشربية، مصباح مدخل، وحوض وضوء.

**السوق** (شارع شرقي-غربي بطول 41م وعرض 6.8م):
- صفَّان متقابلان من 12 محلاً، لكل صف سقيفة (أروقة) بأعمدة خشبية وعوارض وعرائش جريد.
- مظلات/ستائر قماش مخططة (أحمر-كريمي وأخضر-كريمي).
- ساحة وسطى فيها بئر حجري بعارضة ودلو وحبل، محاطة بنخيل.
- بوابة القرية في الطرف الغربي (عقد + دفتان خشبيتان بعوارض حديد).

**المحلات وتجهيزاتها:**

| المحل | التجهيزات |
|---|---|
| فخار وجرار | أزيار على المنضدة والأرض + برج أزيار مقلوبة |
| بقالة وبهارات | أكياس خيش بأكوام بهارات ملوّنة (أحمر/أصفر/برتقالي/أخضر/بني) + صناديق + ميزان + أعشاب معلّقة |
| تمور | سلال تمور + صناديق خشب |
| أقمشة | سجاد معلّق على الواجهة + لفائف قماش |
| قهوة | دكّة + دلال نحاسي + فناجين + منصب شاي |
| بقالة | أكياس رز وطحين + تنك + صناديق |
| أعشاب | حزم معلّقة + سلال + جرار |
| مقهى | دكّتان + دلال + فناجين |
| أدوات | صناديق + أدوات حديد + جرار |

**البيوت**: 5 بيوت شعبية صغيرة (بعضها بدور ثانٍ) + أسوار رابطة.
**التفاصيل**: 7 نخيل + 3 شجر سدر + 9 فوانيس معلّقة + 4 أعمدة فوانيس + إضاءة عملية.

**الكاميرات الجديدة:** `CAM_V3_Street` (الشارع نحو المئذنة) · `CAM_V3_Aerial` (جوية) · `CAM_V3_Souq` (المحلات) · `CAM_V3_Mosque` · `CAM_V3_Over` (عامة).

## الملفات

| الملف | الوظيفة |

| `build.py` | بناء القرية (إضافي للمشهد) + ضبط الإضاءة |

   النتيجة: **2261 → 52 أوبجكت** وهذا مفيد للعبة (draw calls أقل). المجسمات مسبوقة بـ `MESH_`.
