# designs/ — مكتبة تصاميم Blender

كل تصميم في **مجلد مستقل وقائم بذاته**: له سكربت بناء، ملف `.blend`، صور، وشرح.
لا يوجد تداخل بين التصاميم، فتقدر تضيف أي عدد تريده داخل نفس الريبو.

```
designs/
├── README.md                 ← هذا الملف (فهرس + طريقة الإضافة)
├── _template/                ← قالب جاهز تنسخه لأي تصميم جديد
│   ├── build.py
│   └── README.md
├── 001_folk_house/           ← تصميم 001: بيت شعبي نجدي (المشهد الرئيسي)
│   ├── fh_build.py
│   ├── fh_render.py
│   ├── folk_house.blend          ← المشهد النهائي المدمج (52 أوبجكت)
│   ├── folk_house_source.blend   ← المصدر غير المدمج (لإعادة البناء)
│   ├── README.md
│   └── renders/
├── 002_folk_building/        ← تصميم 002: برج حصن + مجلس (مبنى شعبي ثانٍ)
│   ├── build.py
│   └── README.md
└── 003_folk_village/         ← تصميم 003: قرية كاملة (مسجد + سوق + بيوت)
    ├── build.py
    ├── merge_scene.py
    ├── pipeline.py
    ├── README.md
    └── renders/
```

## كيف تضيف تصميم جديد؟ (3 خطوات)

1. انسخ القالب باسم وصفي مرقّم:
   ```powershell
   Copy-Item -Recurse designs\_template designs\002_my_design
   ```
2. عدّل `designs\002_my_design\build.py` (المقاسات، الهندسة، الخامات) ثم شغّله داخل Blender —
   السكربت يحفظ `.blend` بنفس المجلد تلقائياً.
3. أضف سطراً في جدول "التصاميم الموجودة" أعلاه.

## قواعد متّبعة (تخلي المكتبة نظيفة)

- **مجلد لكل تصميم** باسم `NNN_اسم_قصير` بثلاث خانات (001، 002، 010…) — لا تضع ملفات تصميم في جذر `designs/`.
- **السكربت هو المصدر الحقيقي**: `build.py` يجب أن يعيد بناء المشهد من الصفر عند تشغيله
  (`reset_scene()` في بدايته)، لأن `.blend` ملف كبير ويصعب مراجعته.
- **الصور في `renders/`** فقط: النهائية `final_*.png`، والتجارب `prev_*.png` (امسحها عند التسليم).
- **`.blend1`** = نسخة احتياطية تلقائية من Blender؛ تُحذف قبل المشاركة.
- كل تصميم ~0.5MB لملف `.blend` + الصور. رندر 1920×1080 ≈ 2.4MB، فلا تترك عشرات الصور التجريبية.
- المسارات داخل السكربتات نسبية (`os.path.dirname(__file__)`) فلا يهم مكان المجلد.
- `_template/` و`_shared/` محجوزة — لا تضع فيهما تصميماً.

## ملاحظات

- الريبو الحالي **ليس** مستودع Git. لو تبي تتبّع النسخ والرجوع لأي تعديل، أقدر أشغّل `git init`
  وأضيف `.gitignore` يستثني `*.blend1` ومجلد `renders/prev_*`.
- مجلد `art/` في جذر الريبو قديم (بوسترات سابقة) وقواعد مختلفة — لا تخلط معه.
