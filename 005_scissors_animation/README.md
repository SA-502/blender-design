# 005 — أنيميشن منتج: المقص

مقص يتفكّك ويرجع يتركّب ويدور على قاعدة دوّارة، بإضاءة منتجات (Product shot).

## الملفات

| الملف | الوصف |
|-------|-------|
| `scissors_project.blend` | ملف المشروع الرئيسي |
| `scissors_project_111.blend` | نسخة ثانية من المشروع |
| `scissors_scene.blend` | مشهد المقص (شفرات، مقابض، برغي وصامولة، قاعدة دوّارة، كاميرا وإضاءة) |
| `renders/final_cycles.mp4` | الرندر بمحرك Cycles |
| `renders/final_eevee.mp4` | الرندر بمحرك EEVEE |

الفيديوهين: 1920×1080، ‏24 إطار/ثانية، ‏192 إطار (8 ثواني).

## مقارنة وقت الرندر

| المحرك | الإعدادات | الوقت (192 إطار) |
|--------|-----------|------------------|
| Cycles | 64 عينة + Motion Blur | حوالي 26 دقيقة |
| EEVEE | — | 300 ثانية (5 دقائق) |
