# Godot — القرية الشعبية جاهزة للفتح

مشروع Godot 4 يعرض القرية المصدّرة من Blender (`folk_village.glb`) وتمشّ فيها مباشرة.

## الفتح

1. افتح **Godot 4.4+** → Project Manager → **Import**.
2. اختر هذا الملف: `project.godot` (المجلد `designs/godot/`).
3. اضغط **Import & Edit** ثم **F5** (Run Project).

## التحكم

| المفتاح | الوظيفة |
|---|---|
| زر الماوس الأيمن (اضغط باستمرار) | تدوير النظر |
| `W A S D` | تحرّك أفقي/أمامي |
| `Q` / `E` | نزول / صعود |
| `Shift` | سرعة أعلى |
| `Esc` | تحرير الماوس |

## الملفات

| الملف | الوظيفة |
|---|---|
| `project.godot` | إعداد المشروع (Forward+، نافذة 1600×900) |
| `village.tscn` | المشهد: بيئة + شمس + القرية + كاميرا طيران |
| `fly_camera.gd` | سكربت كاميرا الطيران الحر |
| `folk_village.glb` | نفس ملف النموذج الموجود في جذر الريبو |

## ملاحظات

- النموذج مصدّر من مشهد Blender المخرَج: مقياس 1 وحدة = 1 متر، والمحور Y للأعلى في Godot.
- الخامات في GLB **ألوان تقريبية** (الخامات الأصلية إجرائية في Blender). لو تبي المطابقة الكاملة:
  Bake للخامات إلى صور ثم إعادة تصدير GLB بمواد PBR.
- لو أردت القرية كأصول لألعاب: يمكن تقسيم `MESH_*` إلى مجسمات أصغر (كل محل منفصل) لتحسين الـculling.
