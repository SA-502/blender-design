# 004 — بيت شعبي نجدي: النسخة 2 (بعد التحسين)

بيت طين نجدي ببرج وشرفات مدرّجة ونخيل، بنسختين: قبل التحسين وبعده.

## الملفات

| الملف | الوصف | الحجم |
|-------|-------|-------|
| `folk_house_v1.blend` | النسخة الأولى (قبل التحسين) | ~1.3MB |
| `folk_house_v2.blend` | النسخة الثانية بعد التحسين (مضغوط) | ~41MB (أصله 128MB) |
| `renders/final_before.png` | لقطة قبل التحسين | 1920×1080 |
| `renders/final_after.png` | لقطة بعد التحسين | 1920×1080 |

## وش تغيّر في النسخة 2

- رمال بتموجات بدل الأرضية الملساء، وأفق رملي بدل الخلفية السوداء.
- إطارات الشبابيك والباب صارت حجرية بدل الأبيض.
- إضافات حول البيت: جذع شجرة، شجيرات، أعشاب، صخور، جرار فخار، براميل.

## ملاحظة عن الحجم

الملف الأصلي 128MB وهذا أكبر من حد GitHub (100MB للملف)، فانضغط بـ (gzip) إلى ~41MB
مع بقاء الامتداد `.blend`. Blender يفتح الملفات المضغوطة بهذي الطريقة مباشرة.

لو ما انفتح معك: غيّر اسمه إلى `folk_house_v2.blend.gz` وفكّه بـ 7-Zip، يطلع لك الملف الأصلي كامل.

> نصيحة للمستقبل: فعّل في Blender خيار **File → Save → Compress** قبل الحفظ، ينزل حجم الملف كثير.
